# 页然 · Yeran 1.0

**VS Code 式文件管理 × Notion 式块编辑 × Typora 式 Markdown 写作。**

所见即所得的 Markdown 分页编辑器，支持连续写作、A4 预览、横竖混排、打印和 PDF 导出。

- [Windows 安装版（推荐）](https://github.com/bai-lugan/Yeran/releases/download/v1.0.0/Yeran_1.0.0_x64-setup.exe)
- [便携 ZIP](https://github.com/bai-lugan/Yeran/releases/download/v1.0.0/Yeran-1.0-portable.zip)：解压后运行 `Yeran-1.0.exe`。
- [全部附件与校验值](https://github.com/bai-lugan/Yeran/releases/tag/v1.0.0)

Windows x64；需要 WebView2 Runtime，PDF 导出使用本机 Edge 或 Chrome。
