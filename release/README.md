# 页然 · Yeran 2.0.2

**VS Code 式文件管理 × Notion 式块编辑 × Typora 式 Markdown 写作。**

所见即所得的 Markdown 分页编辑器，支持连续写作、A4 预览、横竖混排、打印和 PDF 导出。

支持完整版 Mermaid、对象缩放与左中右对齐、多块选择和成组拖动。2.0.2 加入一行表头建表、离线 Emoji 名称补全，并修复代码围栏输入和粘贴。[更新说明](../PATCH_NOTES_2.0.2.md)

- [Windows 安装版（推荐）](https://github.com/bai-lugan/Yeran/releases/download/v2.0.2/Yeran_2.0.2_x64-setup.exe)
- [便携 ZIP](https://github.com/bai-lugan/Yeran/releases/download/v2.0.2/Yeran-2.0.2-portable.zip)：解压后运行 `Yeran-2.0.2.exe`。
- [全部附件与校验值](https://github.com/bai-lugan/Yeran/releases/tag/v2.0.2)

Windows x64；需要 WebView2 Runtime，PDF 导出使用本机 Edge 或 Chrome。
